## Rule

- **SDS Appendix A:** "Highest test AUC-ROC, with recall as the tie-breaker; the administrator activates the selected version."
- Applied as: rank by test AUC-ROC rounded to 3 decimals (higher first); ties broken by test recall at each model's own tau (higher first).
- **Optimism caveat:** the winner is picked on the test set, so its test AUC is an optimistic estimate of performance on new data (selection on the same data that is reported). The split is grouped by image similarity, not by patient (errata E7), which can also make every test estimate optimistic.
- **One seed (42) in FYP-I.** These are baselines. The final choice is made in FYP-II with 3 seeds (42, 43, 44) and the paired tests below.
